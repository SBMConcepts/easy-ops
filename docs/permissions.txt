===============================================================================
 EasyOps — RBAC Permission Catalog
===============================================================================
 Source of truth : public.role_permissions  (DB)
 Vocabulary      : public.app_permission enum
 Propagation     : post-login Action injects a permissions[] claim on the ID +
                   access tokens; `npm run auth0:sync-rbac` mirrors the same
                   grants into Auth0 native RBAC for dashboard visibility.
 Enforcement     : backend  -> requirePermission()/requireAnyPermission()
                   frontend -> usePermissions().hasPermission()
                   DB        -> public.has_permission(_perm)

 Roles (tenant_role, high -> low): owner > admin > manager > supervisor > employee
   'owner' is a DB-only superset (every permission). The application uses
   'admin' as its top operating tier.

 Legend: [x] granted   [ ] not granted   (status: IMPL = wired to a route today,
   ENUM = in the enum/seed but no dedicated route yet)
===============================================================================

D. FRONTEND GATING
-------------------------------------------------------------------------------
  AuthContext.usePermissions(): hasPermission / hasAnyPermission / hasAllPermissions
  ProtectedRoute requiredPermissions={[...]} (any-of) — used by:
    /app/employees-management  -> read:members
    /app/compliance            -> read:compliance
  SitesAndDepartments page:
    Add/Edit Site        -> manage:sites
    Delete Site          -> admin:tenant
    Add/Edit/Delete Dept -> manage:departments


E. AUTH0 SETUP CHECKLIST
-------------------------------------------------------------------------------
  1. Custom API (Applications -> APIs), identifier = AUTH0_AUDIENCE
     (https://api.easyops.co.za). Enable RBAC + "Add Permissions in the Access
     Token".
  2. Run `npm run auth0:sync-rbac` to push enum -> API scopes and
     role_permissions -> Auth0 roles/grants.
  3. Post-login Action secrets: BACKEND_URL (https://api.easyops.co.za),
     AUTH0_SYNC_SECRET (== server AUTH0_SYNC_SECRET).
  4. Claim namespace must match across Action, frontend (VITE_AUTH0_CLAIM_NS)
     and server (AUTH0_CLAIM_NS): https://easy-ops-za.vercel.app/

  NOTE: Permissions are a global capability layer. Tenant data isolation remains
  enforced by org_id + Postgres RLS — never rely on a permission alone for the
  tenant boundary.
